# Camille's WigglyPaint

A fork of [WigglyPaint](https://internet-janitor.itch.io/wigglypaint) by Internet Janitor, built in [Decker](https://beyondloom.com/decker/).

I was looking for an alternative to WigglyPaint as I really wanted more than 3 colours. Every other alternative didn't have exactly what I was looking for and I didn't want to support copies of the original WigglyPaint so I decided to make my own.

**Try it out:** https://camcheu.github.io/camilles-wigglypaint/

## What I added 
- 16 editable colours with RGB sliders
- Painted colour swatches that auto-update
- Colour labels that name themselves
- Multi-step undo and redo (up to 30 steps)
